# FFMX Android

Estrutura inicial para transformar o painel FFMX em um aplicativo Android com botão flutuante.

## Objetivo
- Tela de acesso ao painel.
- Solicitação da permissão oficial do Android para **Sobrepor a outros apps**.
- Botão/logo FFMX flutuante sobre outros aplicativos quando o usuário conceder a permissão.
- Serviço em primeiro plano para manter o recurso ativo de forma compatível com o Android.
- O botão flutuante é apenas uma interface do FFMX e não modifica, injeta código ou altera o Free Fire.
